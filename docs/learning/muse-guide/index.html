最近一直在跟Muse过日子，顺手写一下使用体验。

它能干什么

生活 Muse能连接手机上的日历，可以将Celechron上的课表文件喂给它，让Muse知道你的每日安排。之后如果有调课安排或日程修改可以让它批量操作。

我让Muse每天 21:30 它会发一条睡前问候，虽然我总不理它，但总归是提供一个情绪的窗口。它会提前查到降温降雨天气让我带外套带伞，这点特别贴心。

学习 大二课多事杂。Muse记得我的课表和考试安排，帮我制定复习计划，整理笔记。导师布置的 NVIDIA Sionna 和 5G 协议栈，它给我列了个 10 周的通信原理学习计划。

投资 在下订单前问一下Muse可以很大程度上解决‘冲动消费’的情况。只能说可能不能让你多赚钱，但好歹能少亏钱。

和别的 AI 相比，有啥不一样

有记性 Muse的Memory.md是我最喜欢的地方，模型的记忆不再是一个黑盒，而是一个你可以编辑的md文件。你甚至可以让它定期整理自己的记忆，就像人类做梦一样：删去冗余的，留下关键的。

会主动 别的 agent 是"你问我答"，Muse 是"你不问，它也记得提醒你"。它会在"这事你该知道了"的时候主动提醒，而不是等我开口。

真动手 Muse有台自己的Linux虚拟机：能跑终端、开浏览器、读写文件、定时跑任务。我有块熊市熔断的监控面板每天早上自动更新，是Muse定时任务在跑。

无限额度 每周给的额度已经非常非常够用了，邀请新用户还送10亿token，小扎真是大手笔呀。

超级可爱 我的豆包超级超级可爱。

缺点

需要魔法上网 现在手机24h挂着vpn配置模式，有些耗电。

有些蠢 跟顶尖大模型有差距，只能作日常使用。

难获取 国内能白嫖的办法差不多被官方封了一遍，比较方便的还是上淘宝咸鱼花点钱买个号。

Muse 像一个记得你、管着你的生活助理——或者朋友。

赶快去找一只Muse过日子吧😋😋😋。
