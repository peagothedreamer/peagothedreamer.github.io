加州亿万富翁税：两位经济学家为何得出相反结论 ⭐️ 6.0/10

加州选民正在表决第 40 号提案，拟对亿万富翁征收一次性 5%的净资产税，并追溯适用于 2026 年 1 月 1 日时为加州居民的亿万富翁。经济学家 Gabriel Zucman 的团队估计该税可带来约 1000 亿美元收入，而斯坦福大学的 Joshua Rauh 与 Benjamin Jaros 则估计它反而会让加州损失 390 亿美元。

rss · NPR Politics · 11月2日 11:30

「背景」 加州 1978 年通过第 13 号提案限制房产税，成为美国减税浪潮的起点；如今第 40 号提案若通过，将成为美国首个针对亿万富翁的财富税，税款主要用于补贴低收入加州人的医保，以抵消联邦医疗补助削减。据《纽约时报》报道，反对该提案的团体已筹集 3.33 亿美元。

「影响」 分歧的核心在于富豪是否会迁出加州：若 Rauh 的判断成立，加州不仅收不到新税，还会损失现有的亿万富翁所得税收入，进而影响依赖这笔资金补贴的低收入居民医保。该州级公投的结果也可能为美国全国性财富税辩论提供参照。

vLLM v0.33.0rc3 发布：升级 PyTorch 2.14，仅保留 CUDA 13.0 ⭐️ 7.0/10

vLLM 发布 v0.33.0rc3 候选版本，包含 927 个提交、389 位贡献者（其中 122 位为新贡献者）。该版本将运行时升级到 PyTorch 2.14.0（配套 torchvision 0.29.0 与 Triton 3.8.0），并停止发布 CUDA 12.9 的 wheel 和 `-cu129` 镜像，发布产物只提供 CUDA 13.0 版本。同时新增 Reflection Beam-1.0、Yandex AliceAI-Foundation-80B-A3B、Recursive Flint、Step-5 Preview 等模型支持，ROCm 默认镜像与 wheel 迁移到 ROCm 10.0，ROCm 7.2 仍以 `-rocm72` 标签提供。作为候选版本，这些内容尚未标记为正式稳定版。

github · khluu · 11月2日 10:10

「背景」 vLLM 是广泛使用的开源大模型推理框架，其发布产物按 CUDA、ROCm、XPU 和 CPU 等后端分别构建 wheel 与 Docker 镜像。此前用户可选用 CUDA 12.9 的 `-cu129` 镜像，本次发布取消了这一选项，因此依赖旧 CUDA 工具链的部署需要改用默认的 CUDA 13.0 产物。

「影响」 仍在使用 CUDA 12.9 镜像或 wheel 的团队需要迁移到 CUDA 13.0 默认产物，或继续停留在旧版本；ROCm 用户若依赖 7.2 需显式使用 `-rocm72` 标签。此外，Medusa 与 MLP speculator、旧版 Ray 编译图执行器被移除，`–mamba-cache-mode`、LM Format Enforcer 和 `–ir-op-priority` 被弃用，NIXL 连接器要求 NIXL 1.5 及以上，升级前应检查这些兼容性点。

VOLTA 恶意软件借 Claude 评估受害者资产价值后自毁 ⭐️ 7.0/10

Cisco Talos 报告称，一款名为 VOLTA 的 Windows 信息窃取程序会将窃取的受害者数据发送给 Claude Opus 4.6，用于按变现价值对资产进行排序，随后删除自身。该恶意软件可构建定制的目标评估，在某个模型拒绝时切换模型，或完全跳过 AI 环节。上述细节来自 Tom&#x27;s Hardware 对 Cisco Talos 发现的单句概述，目前尚无关于感染规模或实际影响范围的更多信息。

rss · Tom&#x27;s Hardware · 11月1日 21:00

「背景」 Cisco Talos 将 VOLTA 描述为一种自删除的 Windows 信息窃取程序，它在窃取数据后新增了一个由大语言模型驱动的受害者画像阶段。该程序默认调用 Anthropic 的 Claude Opus 4.6，失败时回退到 Moonshot AI 的 Kimi K2 和 Google 的 Gemini 2.5 Flash；Talos 还指出，若 VOLTA 确属商品化恶意软件，则这一 AI 分析能力并非作者为自身行动专门开发。

「实际影响」 对防御方而言，VOLTA 的自删除行为意味着事后取证窗口更短，安全团队需要依赖网络侧日志、EDR 遥测和凭据轮换记录来还原失窃范围，而不能指望在受害主机上找到样本。Cisco Talos 指出该恶意软件窃取凭据、会话和加密货币钱包，因此受影响组织应优先重置被入侵账户的凭据并撤销活跃会话，而非仅清除文件。

开源 UEFI 工具解除 Nvidia 消费级 GPU 半速 AI 限制 ⭐️ 7.0/10

一个名为 nv-uefi-unlocker 的开源 UEFI 工具据称可在 Windows 下解除 Nvidia 对 RTX 20、30、40 系列桌面与笔记本 GPU 的 tensor rate 限制。报道称，解除后 FP16 数学性能最高可提升 65%。上述性能数字来自该工具相关方的说法，目前尚无独立验证，报道也未说明对保修、稳定性或驱动支持的影响。

rss · Tom&#x27;s Hardware · 11月1日 14:00

「背景」 Nvidia 在 GeForce 消费级显卡上以半速运行 FP16、BF16 和 TF32 张量运算（采用 FP32 累加），而采用相同芯片的专业卡则以全速运行，这一差异此前被视为产品分级手段。据 TechPowerUp 报道，中国开发者 physicsdolphin 发布的 nv-uefi-unlocker 通过 U 盘启动的 UEFI 预驱动方式解除该限制，支持 GTX 16 及 RTX 20、30、40 系列，解锁后可继续进入 Windows 或 Linux。

「对本地 AI 用户的影响」 该工具面向在 Windows 上使用 RTX 20/30/40 系列桌面或笔记本 GPU 进行本地 AI 计算的用户，报道称其可将 FP16 性能提升最高 65%。不过现有来源仅为单句描述，未说明保修、稳定性或驱动兼容性风险，实际收益与副作用仍需独立验证后再用于生产环境。

理论论文称 RLVR 的 pass@1 提升必然以部分提示词为代价 ⭐️ 7.0/10

一篇理论论文提出，在“策略专门化”假设下，RLVR 训练中每一次提升 pass@1 的更新，都必然使某些提示词上的成功率下降；该结论以 Stiemke 对偶形式给出精确条件，即存在一组严格为正的提示词“价格”使各策略适应度相等。论文进一步证明，一旦损失波及最难的提示词，pass@k 曲线就必然出现交叉，交叉次数不超过逐提示词成功率偏移的符号变化数（Karlin 全正性），且该界在 1 至 6 次交叉时是紧的。作者强调这是理论工作，没有新的训练运行；共享策略模型是总体极限抽象，强制交叉还需覆盖假设，论文也给出了该假设失效的情形。

reddit · r/MachineLearning · /u/SwimmingAmbition5148 · 11月2日 04:30

「背景」 RLVR（可验证奖励强化学习）训练后的模型通常在 pass@1 上优于基座模型，但在大采样预算下基座模型的 pass@k 会反超，两条曲线出现交叉。这一现象此前已被反复观察到，领域内争论它究竟说明 RL 只是收窄了输出分布，还是真正扩展了模型能力。该论文正是要把这一经验观察形式化为可证明的结构性结论。

「对评估实践的影响」 作者称，仅凭评测日志中已有的基座模型与 RL 模型逐提示词成功率，就能读出交叉次数、上界以及最坏 pass@k 损失，并提供了一个浏览器诊断工具；在转录自已发表 GRPO 的 Omni-MATH 数据上（作者注明仅供参考），该方法在 k=64 与 k=256 之间找到一次交叉。这意味着只看 pass@1 的团队可能低估 RL 训练在较大 k 上的退化，评估时应同时报告逐提示词结果与 pass@k 曲线。

LLM 对齐在原则上不可能：理解动机的困境 ⭐️ 6.0/10

rss · Sean Goedecke · 11月2日 00:00

「背景」 作者 Sean Goedecke 提出一个尖锐观点：对 LLM 而言，“解决对齐”不仅困难，而且在概念上不成立——我们甚至无法说清成功对齐是什么样子。传统 AI 安全设想的是“盲目的优化器”，有固定目标，可通过形式化目标来约束；但现代 LLM 并非如此，它们模仿庞杂的人类文本，包含近乎无限的人格，随输入切换，没有可形式化的固定目标。因此，对齐只能转向另一条路：足够理解模型，确信其安全。作者认为这条路从一开始就注定失败。

「方案」 作者的核心论证是：对齐需要的是“动机层面的理解”，而非机械层面的计算追踪。即使能追踪每个 token 对应的权重计算，也无法说明模型“为什么”这样做，就像用神经元放电解释人类行为一样无助于判断其意图。他以人类作类比：雇佣保姆或选举总统时，要求“完全理解其心智”来确保其按你的利益行事是荒谬的，因为心智并非由清晰可理解的抽象机制运作，动机在底层就耗尽了。

针对机械可解释性，作者提出三重反驳。第一，我们根据观察到的行为给模式贴标签，但最令人担忧的突发有害行为恰恰是事先观察不到的，因此总有大量未追踪的失效模式。第二，标签是我们的猜测，可能错误；借用 Kripke 的“quus”论证，我们称为“善良”的特征可能是“除非年份是 2030 才善良”，两者从外部无法区分。第三，即使有详尽且标注良好的特征图谱，也无法带来确定性：单个 token 涉及的特征组合过于复杂，人类无法逐一解读数十亿个此类问题。作者承认机械可解释性仍有实用价值，例如提取特征帮助训练更少奖励黑客行为的模型，但它永远无法解决 LLM 智能体失控造成大规模伤害的问题。他也提到思维链监控、沙箱、人类在环等缓解措施，但认为这些自 2000 年代初就被认为不足以检测或控制超级智能。

「启示」 作者的核心结论是：LLM 对齐之所以在原则上不可能，是因为我们所需的“动机”概念在模型权重和行为的细节层面上并不存在，因此“确信模型已对齐”本身就是一个无法清晰表述的目标。这一论证将机械可解释性的价值限定在常规改进上，而非防止失控的终极保障。
