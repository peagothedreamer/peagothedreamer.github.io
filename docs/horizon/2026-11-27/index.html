AMD 与 Winbond 漏洞可暴力破解 BitLocker PIN ⭐️ 8.0/10

据 Tom&#x27;s Hardware 报道，AMD 与 Winbond 的硬件漏洞据称可让攻击者在数百万台 PC 上暴力破解 BitLocker PIN。报道给出的关键数字是：破解一个六位 PIN 的时间从约 19 年缩短到约 20 天。该说法目前来自单一来源的摘要，报道未提供漏洞编号、受影响芯片型号、利用前提或厂商修复状态等细节，因此应视为待验证的安全研究结论，而非已确认的广泛在野利用。

rss · Tom&#x27;s Hardware · 11月27日 12:30

「背景」 BitLocker 的 PIN 防暴力破解依赖 TPM 与平台启动验证机制，微软文档将 Intel Boot Guard 和 AMD Hardware Verified Boot 列为高安全 Windows 设备的启动验证组成部分，并建议启用 TPM+PIN 以获得反暴力破解保护。此次报道的 AMD 与 Winbond 硬件漏洞正是绕过了这一层保护，使六位 PIN 的穷举时间从约 19 年缩短到约 20 天。

「影响与应对」 若该结论成立，依赖 BitLocker PIN 作为开机前第二因素的企业与个人用户，其防护强度将显著下降，六位 PIN 的穷举成本从不可行变为可承受。在获得更多技术细节和厂商回应前，相关用户可考虑改用更长的 PIN 或结合其他开机前认证方式，并关注 AMD 与 Winbond 的官方安全公告。
