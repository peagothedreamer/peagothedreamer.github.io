OpenAI 宣称在数学、计算机科学与物理领域取得三项发现 ⭐️ 8.0/10

OpenAI 发布公告，称在调和分析、复杂性理论和量子场论三个方向取得三项新发现，其中一项结果涉及复杂性理论中的指数时间假设（ETH）。公告附带的论文摘要给出一个确定性算法，用于精确统计任意 k-CNF 公式的满足赋值数：对每个固定 k ⩾ 2，在 n 个变量、m 个子句的公式上使用 poly_k(n, m) 空间，运行时间为 (n + m)^{O_k(1)} 2^{n/(log n)^{1/2 + o(1)}}。该复杂度仍为超多项式，但低于指数级；若成立，将构成对 ETH 的反驳。目前这些结果来自 OpenAI 的公司公告与论文，尚未见到独立验证。

hackernews · jonluca · 10月26日 21:35 · 社区讨论

「背景」 指数时间假设（ETH）是计算复杂性理论中由 Impagliazzo 与 Paturi 提出的未证明难度假设，认为 3-CNF 布尔公式的可满足性无法在亚指数时间内求解。细粒度复杂性领域的许多下界与硬度证明都建立在 ETH 成立的前提上，因此若该假设被推翻，相关结论的根基将受到影响。

「影响与待验证之处」 指数时间假设是参数化复杂性等领域许多下界与硬度证明所依赖的前提；若上述算法及其分析经同行验证成立，相关领域的部分既有结论需要重新审视。在独立复核完成前，研究者和工程团队不宜把该公告当作已确立的结论使用。

微软修复安卓版 Authenticator 高危令牌窃取漏洞 ⭐️ 7.0/10

微软修复了 Android 版 Microsoft Authenticator 的一个高危漏洞，该漏洞可能让已安装并运行的恶意应用在未申请安卓权限的情况下获取已登录工作账户的令牌。修复版本为 6.2606.4246。研究人员称攻击无需用户进一步操作，但微软认为攻击者需诱使用户完成身份验证；微软首次发布公告时表示未发现该漏洞被实际利用。

telegram · zaihuapd · 10月27日 12:04

「背景」 该漏洞被登记为 CVE-2026-80097，归类为 Microsoft Authenticator 中的“身份验证不当”，可让本地攻击者提升权限。公开漏洞库将其描述为本地权限提升问题，而本次来源进一步指出，恶意应用可借此获取已登录工作账户的令牌。

「影响与应对」 依赖 Authenticator 进行工作账户多因素认证的企业和安全团队应尽快将安卓客户端升级至 6.2606.4246 或更高版本，以消除令牌被本地恶意应用窃取的风险。由于微软与研究人员对攻击是否需要用户交互存在分歧，实际风险程度仍不完全确定。
