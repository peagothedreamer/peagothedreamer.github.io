美联储调整会议安排：2027 年 10 月会议将不进行利率投票 ⭐️ 7.0/10

美联储宣布，2027 年 10 月 26 日至 27 日的会议将不进行利率投票，也不发布会后声明，而是专门用于讨论广泛的货币政策战略问题；2027 年全年将有七次投票会议，年内最后一次会议从 12 月提前至 11 月。

rss · CNBC Finance · 11月12日 19:05

「背景」 凯文·沃什自 2026 年起担任美联储主席，上任后推动改变货币政策沟通方式，包括缩短会后声明、减少前瞻性指引。按照以往惯例，美联储每年召开八次会议，每次都会就利率进行投票并举行记者会。

「市场影响」 这一调整要到 2027 年才生效，不改变当前利率，但会减少市场从 10 月会议获得的利率信号：该次会议将不投票、不发会后声明，投资者届时只能依据 11 月会议判断政策方向。对依赖美联储定期指引来定价利率路径的债券投资者和利率敏感型股票而言，全年可参考的正式决议次数将从惯例的八次降为七次。

Apache HTTP Server mod_http2 曝未授权远程代码执行漏洞，2.4.71 修复 ⭐️ 8.0/10

Apache HTTP Server 的 mod_http2 模块存在一个无需认证即可触发的远程代码执行漏洞，编号为 CVE-2026-119618，修复版本 2.4.71 已发布。该漏洞仅影响启用了 HTTP/2 的环境。上述信息来自一篇简短的二手博客摘要，未提供漏洞触发条件、受影响版本范围或利用细节，也未见官方安全公告作为佐证。

rss · 情报の灯台 / Joho no Todai · 11月13日 00:25

「背景」 该漏洞源于 mod_http2 模块中的竞态条件，可使未认证的远程攻击者破坏堆内存，进而可能导致远程代码执行。据安全厂商的分析，受影响版本为 Apache HTTP Server 2.4.55 至 2.4.70，修复版本为 2.4.71。

「影响与处置」 受影响范围为 Apache HTTP Server 2.4.55 至 2.4.70，以及单独分发的 mod_h2 模块 2.0.8 至 2.0.42；修复版本 2.4.71 已于 2026 年 11 月 11 日发布。Wiz 建议将受影响的 Apache HTTP Server 升级到 2.4.71 或更高版本，该版本修复了 assign_headers() 中的竞态条件。仅启用 HTTP/2 的部署需要优先排查。

hackernews · mbStavola · 11月12日 18:39 · 社区讨论

「背景」 never 类型（`!`）自 2015 年起进入 Rust 的长期开发轨道，此前长期处于不稳定状态，本次 1.100 将其稳定化，并把 2015、2018、2021 edition 的 never 类型回退行为从 `()` 改为 `!`，与 Rust 2024 保持一致。Cargo 的依赖冷却机制则源自 RFC 3923，允许在配置后让解析器忽略发布时间过新的版本，除非该版本已记录在 Cargo.lock 中。

「对开发者的影响」 依赖冷却配置为团队提供了一种在 Cargo 层面延迟采用新发布版本的机制，但已锁定在 Cargo.lock 中的版本不受影响，因此现有构建不会因启用该配置而改变。cargo install 默认改用包内锁文件后，依赖 –locked 强制锁定行为的脚本需要确认其语义变化；未使用依赖警告默认开启，可能让现有项目在构建时出现新的警告。

「社区讨论」 评论者普遍欢迎此次发布，有人特别提到 never 类型和自定义分配器的稳定化，以及依赖冷却和 cargo install 锁文件行为的变化。也有用户抱怨编译速度慢、需要频繁清理大量临时文件，并询问编译器是否变快；另有评论指出发布说明遗漏了若干同样有用的稳定 API。
