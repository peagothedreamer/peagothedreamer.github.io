OpenSec 披露 Linux nfsd 9.8 分预认证漏洞 ⭐️ 8.0/10

OpenSec 披露了 Linux 内核 NFS 服务器（nfsd）中的预认证堆溢出漏洞 CVE-2026-99362，CVSS 评分为 9.8。攻击者无需登录，只需向 tcp/2049 发起一条连接即可越界写入内核堆，进而获取 root shell。该漏洞自 2014 年的 Linux 3.16 起存在，影响启用 NFSv4.1 或 4.2 的主机，波及文件服务器、NAS 和集群存储节点。修复已在 6.12.117、6.18.61、7.3.2 和 7.4-rc1 中发布，需升级内核并重启；无法立即升级的环境可通过防火墙限制 tcp/2049 访问。CVE 于 2026 年 11 月 20 日公开。

telegram · zaihuapd · 11月27日 12:57

「背景」 nfsd 是 Linux 内核中提供 NFS 文件共享服务的组件，NFSv4.1 和 4.2 是其较新的协议版本，广泛用于文件服务器、NAS 与集群存储。该漏洞的根源可追溯至 Linux 3.16，意味着此后长期运行 NFSv4.1/4.2 服务的主机都可能处于受影响状态。

「影响」 运行受影响内核并对外提供 NFSv4.1/4.2 服务的主机面临无需认证的远程 root 风险，运维团队应优先升级至 6.12.117、6.18.61、7.3.2 或 7.4-rc1 并重启；若无法立即升级，应通过防火墙限制对 tcp/2049 的访问作为临时缓解。

Unkernel：把真实 Linux 内核编译为 WebAssembly ⭐️ 7.0/10

Unkernel 将真实的 Linux 内核编译为 WebAssembly，使 Linux 环境能在浏览器中快速启动。该项目在 Hacker News 上引发关注，并已出现基于它的衍生项目。现有信息未说明支持的内核版本、浏览器兼容范围或性能数据，因此其可用性仍以项目页面为准。

hackernews · nreece · 11月28日 03:19 · 社区讨论

「背景」 Unkernel 的核心做法是把 Linux 内核直接编译为 WebAssembly，而不是在浏览器里运行一个模拟整机的传统虚拟机；用户程序运行在 kwemu 上，这是一个用 Zig 编写并链接进内核的 aarch64 CPU 实现，它遍历内核自身的页表，因此内存管理仍由真实的 Linux 代码完成。据项目页面介绍，它能在不到一秒内启动到 shell。

「社区讨论」 有评论者称启动速度很快，并认为 Wayland 合成器性能出色；gregbell 表示自己基于 Unkernel 完成了衍生项目 unlab，并称“困难的部分都由 unkernel 完成”。另有评论者提出，可借此在浏览器中运行 Windows 程序并配合 WebUSB 使用，也有人认为教育平台可让每名学生获得独立的浏览器内 Linux 环境。这些均为个人观点或设想，并非已验证的结论。

SAP 承认 GitHub 开发环境遭入侵，员工认证令牌被窃 ⭐️ 7.0/10

SAP 承认其 GitHub 开发环境遭到入侵，攻击者获取了员工的认证令牌，从而具备复制或修改源代码的能力。目前公开的信息仅为简要概述，未披露入侵范围、受影响产品、修复措施及对客户的具体影响。

rss · 情报の灯台 / Joho no Todai · 11月28日 12:12

「背景」 此次事件的核心风险在于开发环境中的认证令牌：攻击者一旦取得员工令牌，便可能以该员工身份访问托管在 GitHub 上的代码仓库，从而复制或改动源代码。据 SecurityWeek 与 Cybersecurity News 等报道，SAP 是在发现 GitHub 上的可疑活动后确认并调查这起安全事件的，DER SPIEGEL 则报道称攻击者窃取了 SAP 员工的认证令牌。目前公开信息尚未说明受影响仓库、产品范围及修复措施。

「影响」 由于攻击者可能已复制或改动机密源代码，依赖 SAP 软件的企业客户面临供应链风险：被篡改的代码若进入构建或发布流程，下游部署可能受到影响。SAP 目前仅确认正在调查可疑的 GitHub 活动，尚未公布受影响的产品、代码范围或修复措施，因此客户和集成方在官方结论出台前难以评估自身暴露面。

中国 AI 硬件布局延伸至 PCB 上游材料与钻针 ⭐️ 7.0/10

据 Tom&#x27;s Hardware 报道，中国的 AI 硬件产业推进正从 GPU 本身扩展到其下方的印制电路板（PCB）供应链，重点转向铜箔和微钻针等上游材料与工具。报道称，随着 AI 服务器（如 Rubin Ultra）的 PCB 层数向 78 层推进并使用更致密的层压材料，钻针磨损速度达到正常情况的 10 倍，高速信号传输也推高了对光滑铜箔的需求。该报道基于简短摘要，未给出具体政策举措、企业名称或量化的市场规模与财务影响，因此中国“争夺”这些环节的具体程度仍不明确。

rss · Tom&#x27;s Hardware · 11月27日 17:00

「背景」 AI 服务器主板层数增加、信号速率提升，使瓶颈从芯片本身向上游材料和加工环节转移：更致密的覆铜板、更光滑的铜箔以及更耐磨的微钻头成为关键投入品。行业分析指出，加速卡板、交换板、电源板和背板对 PCB 的要求各不相同，因此相关需求会进一步传导至层压板、电子级玻纤布、铜箔和制造产能。

「影响」 若上游铜箔与微钻头供应趋紧，AI 服务器 PCB 制造商将面临更短的钻头寿命和更高的层数成本压力；报道提到每增加一层 PCB 约使制造成本上升 20%–30%，而 Rubin Ultra 等平台朝 78 层推进。相关企业需提前评估铜箔与钻头采购来源及替代供应，以降低断供风险。

据 Tom&#x27;s Hardware 汇总的多份报道，亚洲地区 GPU 租赁漏洞被收紧，加上针对模型蒸馏的打击，可能使中国 AI 模型相对竞争对手落后最多九个月。报道称这些因素正在对中国 AI 实验室形成压力，但所给材料仅为一周内多份报道的概述，九个月差距的具体测算依据、涉及哪些实验室以及漏洞关闭的执行范围均未在原文中给出，相关说法应视为报道方的评估而非已独立验证的结果。

rss · Tom&#x27;s Hardware · 11月27日 15:00

「背景」 美国对华先进 AI 芯片出口管制已实施多年，限制英伟达高端 GPU 直接销往中国。此后，通过境外云服务商租用 GPU 算力成为部分中国 AI 实验室绕开硬件限制的途径之一，而近期的执法收紧正针对这一渠道。与此同时，模型蒸馏——即用更强模型的输出训练自家模型——也是追赶前沿能力的常见手段，相关限制会直接影响这一路径。

美国 ITC 裁定三星侵犯 Maxell 相机专利，Galaxy S25 面临进口禁令 ⭐️ 7.0/10

美国国际贸易委员会（ITC）认定三星侵犯了 Maxell 持有的美国专利 11,490,004（相机取景相关），并签发了有限排除令和进口禁令，覆盖 Galaxy S25 系列手机及部分 Galaxy 平板。Maxell 于 2024 年 12 月就 5 项相机专利提出申诉，ITC 最终只认定其中 1 项被侵犯。该禁令自 11 月 25 日起进入 60 天总统审查期，期间三星仍可在美国销售相关产品；已售出设备、保修更换设备以及改用重新设计相机系统的机型获得豁免，三星表示已改版相机系统以规避该专利。

智利 FNE 起诉苹果，寻求 8000 万美元罚款并强制开放侧载 ⭐️ 7.0/10

智利国家经济检察院（FNE）已对苹果提起反垄断诉讼，指控其在 iOS 应用分发和应用内购买市场滥用主导地位。FNE 寻求 8000 万美元罚款，并要求苹果允许侧载、第三方应用商店和替代应用内支付系统，同时允许开发者引导用户至外部支付渠道。苹果表示已知悉请求并将继续配合调查，称 App Store 旨在保障用户安全与信息安全，否认在任何市场形成垄断，并反对 FNE 对相关市场的界定。该消息经 Telegram 聚合渠道转述，细节有限。

「背景」 智利国家经济检察院（FNE）是负责竞争执法的国家机构，此次诉讼针对的是苹果在 iOS 应用分发和应用内购买市场的支配地位。苹果在回应中反对 FNE 对相关市场的界定，这一界定将决定其行为是否构成滥用。
