## 工程与思考

<a id="item-tech-blog-1"></a>
### [NVIDIA cuPhoton.xBeam：GPU 加速黑洞干涉测量](https://developer.nvidia.com/blog/run-gpu-powered-black-hole-interferometry-with-nvidia-cuphoton/) ⭐️ 7.0/10

rss · NVIDIA CUDA Technical Blog · 11月13日 21:17

**「背景」** 事件视界望远镜（EHT）通过甚长基线干涉测量（VLBI）将全球多台射电望远镜同步记录的高速电压流关联起来，以重建黑洞图像；下一代 EHT 计划增加站点，数据量将达 PB 级，传统 CPU 相关器成为瓶颈。

**「方案」** 作者详细介绍了 NVIDIA cuPhoton.xBeam 这一 GPU FX 相关器：它先为 VDIF 记录建立 .vdix 索引以便并行读取，再在 GPU 上依次完成延迟与条纹校正、FFT 信道化、台站对交叉相乘与积分，最后输出 DiFX SWIN 或 xbeam-v1 格式的可见度。延迟模型来自作业文件中的几何延迟多项式、钟差和频段固定偏移，fringe\_approximation\_order 控制 FFT 内延迟的 0/1/2 阶近似；xBeam 本身不计算延迟，也不追踪黑洞附近光路。数据可通过 POSIX 固定主机内存或 cuFile/GPUDirect Storage 进入 GPU，多 GPU 按时间分片（--shard-count/--shard-index），merge-shards 在校验作业一致性和时间覆盖后合并结果。作者报告在 Vera Rubin NVL72 的 64 GPU 上，10 TB 数据端到端处理耗时 70 秒，约为 x86 CPU 基线 31,992 秒的 460 倍；读取带宽从 4 GPU 的 20 GB/s 增至 64 GPU 的 170 GB/s。这些是厂商在特定系统上的基准，方法细节有限；下游校准与成像不在教程范围内，AI 代理部分属于展望。

**「启示」** 作者认为，将相关器的延迟校正、FFT 和交叉相乘全部放到 GPU 上，并按时间分片扩展，能显著缩短 VLBI 海量数据的处理时间，为 ngEHT 等下一代观测提供可行的数据管道基础。
